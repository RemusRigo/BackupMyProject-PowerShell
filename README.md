# Backup My Project
Backup My Project: a PowerShell script that archives a project folder (or file) into a zip file, from the **Send to** menu



## Author

* [@remusrigo](https://github.com/RemusRigo)
* [@remusrigo](https://sourceforge.net/u/remusrigo/profile)



## Features

* Right-click a folder or file → **Send to** → **BackupMyProject.bat**
* The archive is named after the project: `<project folder>.zip`, next to the project folder
* Each backup is added to the same zip, in a folder named with the date and time of the backup (e.g. `2025-07-22 14-30`)
* `Install.bat` creates the **Send to** shortcut
